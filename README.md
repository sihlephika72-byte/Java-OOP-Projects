# COS101 - Object-Oriented Programming Practicals (Java)

Welcome to my repository for **COS101 (2026)** at the **University of the Western Cape (UWC)**! 🏛️ 

This repository tracks my journey learning Object-Oriented Programming (OOP) principles in Java using **IntelliJ IDEA**. Each practical exercise is structured inside its own Java package to demonstrate modular code design, encapsulation, and clean software architecture.

---

## 📚 Topics Covered

Throughout these practical tasks, I have implemented and mastered the following fundamental OOP concepts:

* **Encapsulation & Access Control:** Using `private` and `protected` fields with `public` getters/setters ("bouncer logic") to maintain data integrity.
*  **Constructors & Chaining:** Utilizing overloaded constructors and explicit superclass constructor calls (`super(...)`).
*  **Inheritance & Hierarchy:** Extending base classes to build specialized subclasses and promoting code reuse.
*  **Abstract Classes & Interfaces:** Defining strict contracts using `interface` and `abstract` classes to support polymorphic behavior.
*  **Polymorphism & Dynamic Dispatch:** Processing arrays of base-class references and overriding methods (`toString()`, `calculatePay()`, `withdraw()`).
*  **Downcasting & Runtime Checks:** Safely casting objects using the `instanceof` operator.
*  **Static State Tracking:** Using `static` variables and methods to keep track of class-level counters.
